# Conway Game of Life

Реализация клеточного автомата **Conway's Game of Life** на Python.

Проект выполнен в рамках тестового задания, но в процессе разработки был расширен и спроектирован как небольшая основа для реализации различных клеточных автоматов с разделением симуляции, движка и пользовательского интерфейса.

## Демонстрация
  ![Demo](docs/conway_demo.gif)

## Возможности

* поле размером 20×20;
* тороидальное игровое поле;
* ручное редактирование клеток;
* пошаговое выполнение симуляции;
* возврат к предыдущим поколениям;
* определение состояний симуляции:

  * обычное выполнение;
  * отсутствие живых клеток;
  * стабильная конфигурация;
  * повторяющаяся (циклическая) конфигурация;
* интерактивный консольный интерфейс.

## Архитектура

Проект разделён на несколько независимых частей:

```
engine/       игровой цикл и обработка команд
simulation/   логика клеточного автомата
ecs/          хранение сущностей, компонентов и систем
ui/           консольный пользовательский интерфейс
```

Состояние клеток хранится с использованием собственной реализации ECS (Entity Component System). В текущей реализации клетка состоит из компонентов позиции (`Position`) и состояния (`State`), а логика изменения состояния вынесена в отдельную систему.

Такое разделение позволяет изменять правила автомата, не затрагивая пользовательский интерфейс и игровой цикл.

### Архитектурные особенности

Несмотря на то, что в рамках тестового задания реализован только автомат Конвея, проект изначально проектировался как основа для различных клеточных автоматов.

Игровой цикл, пользовательский интерфейс и логика симуляции разделены между собой, а правила автомата инкапсулируются в отдельных системах и конфигурациях.

## Управление
> Управление использует английскую раскладку клавиатуры.

| Клавиша   | Действие                  |
| --------- | ------------------------- |
| ← ↑ ↓ →   | Перемещение курсора       |
| Space     | Изменить состояние клетки |
| Enter     | Следующее поколение       |
| Backspace | Предыдущее поколение      |
| Q         | Выход                     |

## Особенности реализации

В отличие от классического варианта задания, при обнаружении терминального состояния (отсутствие живых клеток, стабильная или циклическая конфигурация) программа **не завершает работу**, а отображает текущее состояние симуляции.

Это позволяет продолжить редактирование поля и исследование поведения автомата без повторного запуска программы.

## Запуск

Требуется Python 3.10 или новее.

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск:

```bash
python main.py
```

Для Windows также приложен готовый исполняемый файл, собранный с помощью PyInstaller.
